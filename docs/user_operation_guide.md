# User Operation Guide

This is the operator reading of the current workstation. It does not enable trading.

## What you can see

- **Home** answers whether anything is connected, whether trading is allowed, and the one safe next step.
- **Gold** shows the last recorded quote. A connection is not a price, and a price is not a trade.
- **Recorded quotes** saves quotes. Recording never submits an order.
- **Demo account** is a practice account. Demo trading stays off until a recorded authorization and the safety checks both allow it. A connection is not permission.
- **Practice** shows simulated fills and would-be trades. Nothing there is sent to a broker.
- **Order history** shows orders the broker accepted, rejected, or left unfinished. It does not place an order.
- **Risk** shows the limits. A clear reading is not permission to trade.
- **Reports** show saved research. A missing report stays missing.

## What stays locked

- Live trading stays locked. No page, button, research file, or demo result in this workstation can open it.
- Real-money exposure stays at zero.
- There is no validated trading opportunity. A backtest pass is not permission to trade.
- The header **Stop trading** raises the kill switch. It does not close an open broker position. If the request fails, the screen says the stop was not confirmed.

## What this guide does not do

It does not connect to a broker, pin an account, submit an order, or turn execution on. Setup can store a terminal path. Credentials are not stored here. A mock terminal is not broker evidence.
