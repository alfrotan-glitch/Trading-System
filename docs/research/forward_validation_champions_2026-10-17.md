# Forward-validation protocol — frozen champions `ts9_lo` / `veto9`

**Frozen 2026-10-17, before any forward month exists.** This protocol
changes no parameter, gate or threshold of any completed cycle. It
exists because the only evidence that can still move the verdict is
data that does not yet exist (see `best_edge_2026-10-17.md` §4).
Nature: **paper observation only** — no orders, no broker connection,
no DEMO/LIVE/risk state is touched by forward observation.

## 1. Frozen rules (verbatim, `src/qts/research/longhistory/forward.py`)

Monthly decision at each published month-end `t`, executed (on paper)
at month `t+1`'s average price (the research TWAP convention):

- **`ts9_lo`**: long if trailing 9-month gold return > 0, else flat.
- **`veto9`**: sign of the 9-month gold trend; a short is taken only
  while the equal-weight USD index (Fed H.10 8-currency basket, monthly
  method of the parent cycles) rose over the prior 12 months, else flat.
- Sizing (both): fraction = clip(0.10 / (12-month realised vol × √12),
  max 1.0) of paper equity $10,000, `fixed_units.v2` accounting, no
  leverage, no stops.

## 2. Starting record (2026-09-30, last published month)

`data/evidence/longhistory/forward_champions_state.json`, generated by
`scripts/forward_champion_state.py --record`: **both champions LONG
since 2023-02, size fraction 0.473**, on a trailing 9-month gold return
of **+0.2%** — i.e. one soft monthly close from flipping flat. The
forward clock starts here; nothing before 2026-10 counts forward.

## 3. Forward data

Each new month is appended from the same public sources by the same
method (World Bank Pink Sheet monthly gold average; Fed H.10 daily FX
→ basket index with the documented quote convention and ≥6/8 month-end
coverage). Source and publication date are logged per month in the
state record. A method change, a restated history that alters a past
state, or a missing month **voids** the forward record rather than
being repaired silently. Costs: ASSUMED base until measured MT5 demo
costs exist (Windows terminal); the cost basis of every evaluation is
stated with it.

## 4. Pre-declared checkpoints (no interim peeking verdicts)

- **Month 12 (2027-09):** record only — states, paper equity, turns.
- **Month 24 (2028-09):** *continuation test.* Continue only if both
  champions' forward-only paper Sharpe > 0 net of the stated costs.
  Otherwise retire both and close the programme as `NO_VALIDATED_EDGE`.
- **Month 36 (2029-09):** *re-evaluation.* Recompute the gate chain
  with forward months appended to the out-of-sample sample and the
  trial count frozen at N = 262 (no new configurations). Promotion
  still requires every gate, MEASURED costs for any economic claim,
  and owner/governance steps outside this protocol. A pass would be
  `FORWARD_VALIDATION_CANDIDATE_ONLY` at most; this protocol can never
  by itself unlock live trading.
