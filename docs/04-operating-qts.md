# 4. Operating QTS

## Operator mental model

QTS reports what it can prove, distinguishes a broker fact from a simulation or research result, and fails closed when information is missing. `NO_VALIDATED_EDGE` remains the research verdict. `LIVE` remains locked and `REAL_CAPITAL_EXPOSURE = 0`.

The registered DEMO provider is `DEMO-XAUUSD-TREND-TSMOM-V1`: completed-bar XAUUSD M15 EMA(12/48), a fixed registered size of 0.01 lots, a USD 3.00/oz XAUUSD quote-price-distance stop (not a dollar-loss cap) and a four-hour maximum hold. It is a DEMO diagnostic, not a validated trading edge. The separate monthly `ts9_lo` / `veto9` research candidates are paper-only and are not connected to this order path.

The Trading page's EMA panel is a **read-only history snapshot**. It may show a bullish/bearish relationship or a cross on the latest completed historical bar, but seeding never emits that historical cross as a live signal. The manual order ticket is not generated by that panel. Every manual request requires an explicit confirmation, a fresh backend preflight, and the normal authoritative safety gates.

## 1. Reading the Home screen

When opening the QTS Workstation (`#/home`), the first screen answers five operational questions:

1. **What is happening?** System status and the DEMO-account connection are stated plainly. Gold appears only when the price is fresh; otherwise QTS says it is unavailable.
2. **Is there an opportunity?** Home reports whether a validated strategy exists. It currently says no validated trading opportunity; no candidate is presented as profitable or validated.
3. **Can QTS request a DEMO action?** The Trading page reports the current DEMO workflow state and its ordered blockers. Passing those checks is not an edge claim and does not bypass per-order preflight.
4. **Is real money at risk?** No. The product remains DEMO-only, `LIVE` is locked, and reported real-capital exposure is `$0`.
5. **What should I do next?** The backend provides one primary next action. Details are under **Advanced** and **Technical details**.

## 2. Safe operating workflows

### A. Market observation — zero orders

1. Open **Advanced → Recorded observations** (`#/advanced/data-observations`).
2. Select **Start Observation**.
3. Quotes are stored in the machine-local observatory database, outside the repository checkout.
4. Observation submits no orders and does not grant execution permission.

### B. Read-only DEMO inspection

Before connecting to a broker, confirm that your account and region are eligible directly with WM Markets. On 2026-10-18, the broker's public pages returned a regional-restrictions notice in this session; account eligibility and current account-specific XAUUSD terms were not verified. Do not attempt to bypass a restriction.

On an authorized Windows workstation with MT5 available, start with read-only checks:

```bat
qts demo verify
qts demo connectivity --json-out "%LOCALAPPDATA%\QTS\cost-audit\connectivity.json"
qts demo symbol-terms --json-out "%LOCALAPPDATA%\QTS\cost-audit\symbol_terms.json"
qts demo spread-profile --samples 60 --interval-sec 5 --json-out "%LOCALAPPDATA%\QTS\cost-audit\spread_overlap.json"
qts demo cost-check --json-out "%LOCALAPPDATA%\QTS\cost-audit\cost_check.json"
```

Create the local output directory first. Reports can contain account and broker identifiers: keep them machine-local, do not commit raw files or deal-level evidence, and share only a sanitized summary. `connectivity` without `--pin` is a probe. `--pin`, `--confirm-pin`, `--record`, mode declarations, arming and re-verification change local state; they are not read-only steps.

A missing commission, swap, spread or slippage measurement remains `UNAVAILABLE` / `UNKNOWN`, never zero. A quoted spread or symbol specification alone is not a complete all-in cost model. Use the Reports page and the measured-cost runbook to keep spread, commission, slippage and financing basis separate.

### C. DEMO execution — separate authorization required

Do not arm, refresh permission, start the autopilot or place an order as part of read-only inspection. Those are state-changing operations. A non-dry-run autopilot session can submit orders if a future completed-bar crossover occurs; it requires a separate operator decision and explicit `--confirm --risk-ack` flags. It must never be started just to produce test evidence.

If an authorized operator deliberately chooses a DEMO measurement, use the registered strategy ID and the existing gated path:

```bat
qts demo run --strategy DEMO-XAUUSD-TREND-TSMOM-V1 --confirm --risk-ack
```

This is an order-capable command, not a health check. Review `qts demo run --help` and `qts demo verify` first. Do not use `--dry-run` results as fills or broker verification. No order was attempted during this audit.

A manual order is a separate operator-selected diagnostic, not a signal from EMA(12/48). The desktop page requires a no-order preflight and a confirmation showing size, stop and estimated stop-distance risk; the backend repeats all gates at submission. The CLI's `qts demo order` also requires both `--confirm` and `--risk-ack` for a non-dry-run order. Never send an order to measure a cost that can be observed from existing broker deals.

## 3. Emergency stop and recovery

### Raise the kill switch

If broker behavior, latency, connectivity or reconciliation is unexpected, use **Stop trading** in the UI or:

```bat
qts demo kill --reason "Operator manual intervention"
```

The durable kill switch prevents further submissions. It does not close an open broker position; position closure is a separate, explicitly confirmed action.

### Clear the kill switch

Clearing requires a deliberate reason and confirmation:

```bat
qts demo clear-kill --reason "Investigated and cleared" --confirm
```

Clearing does not re-arm execution. The stage remains halted until the operator separately completes the gated DEMO preparation workflow. Do not clear a stop to dismiss an unresolved broker or journal discrepancy.

## 4. Broker and research limits

- The MT5 Python integration is Windows-only; this Linux audit did not connect to a terminal, account or broker.
- WM Markets' public product and rollover tables did not render in the retrieved pages. Current account-specific XAUUSD spread, commission, swap, contract size and DEMO terms remain unverified.
- The broker pages returned a regional-restrictions notice. Confirm eligibility with WM Markets before any connection; do not circumvent it.
- Historical research costs are assumptions unless the evidence explicitly marks each component `MEASURED`. A historical spread sample is not a current quote or a fill-cost measurement.
- DEMO fills, strategy snapshots, backtests and paper/shadow results are distinct evidence classes. None by itself validates a live edge.
- Read `docs/windows_demo_runbook.md` before any Windows MT5 cost capture. It separates no-order probes from state-changing actions and includes the current research verdict and limitations.
