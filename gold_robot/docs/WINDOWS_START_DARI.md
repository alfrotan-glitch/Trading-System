# شروع ساده QTS Gold در ویندوز

**یک پروژه، یک شاخه اصلی، یک فایل برای آغاز:** `START_HERE.bat`

هدف این نسخه نصب آسان QTS Gold Robot روی **Windows + WMMarkets MT5 + XAUUSD@** و آزمایش منظم استراتیژی‌ها است. این نسخه **برای حساب واقعی آزاد نشده** و سودآوری تأییدشده ندارد.

## فقط این چهار قدم

۱. ترمینال **MetaTrader 5 متعلق به WMMarkets** را روی ویندوز نصب و باز کنید. برای تست، از حساب Demo استفاده کنید. اگر قبلاً EA قدیمی QTS را روی چارت وصل کرده‌اید، ابتدا آن را جدا کنید.

۲. سورس جدید را از شاخه `main` بگیرید:

```powershell
git clone --branch main --single-branch https://github.com/alfrotan-glitch/Trading-System.git
cd Trading-System
```

اگر پروژه قبلاً روی همان کمپیوتر Clone شده و فایل محلی تغییر نکرده است: `git pull --ff-only origin main`. از پوشه‌های قدیمی ZIP و سورس تازه در یک پوشه مشترک استفاده نکنید.

۳. روی **`START_HERE.bat`** دوبار کلیک کنید و گزینه **1** را بزنید.

این گزینه ربات اصلی `QTS_Gold_Robot.mq5` را همراه `ExecutionPolicy.mqh` و `StructureResearch.mqh` نصب و در MetaEditor کامپایل می‌کند. بعد اسکریپت `QTS_Broker_Preflight` را نصب می‌کند. محل نصب موجود را Backup می‌گیرد و اگر کامپایل موفق نشود فایل‌های قبلی را برمی‌گرداند.

**معیار موفقیت: `Result: 0 errors, 0 warnings` و ساخت EX5 جدید.** خروجی نصب فقط سورس را کامپایل می‌کند؛ Algo Trading را روشن نمی‌کند و سفارشی ارسال نمی‌کند.

۴. در MT5 یک چارت `XAUUSD@` باز کنید. در **Navigator → Scripts** گزینه Refresh را بزنید؛ `QTS_Broker_Preflight` را روی چارت اجرا کنید. سپس از `START_HERE.bat` گزینه **2** را انتخاب کنید. گزارش وضعیت در مرورگر باز می‌شود و داخل `gold_robot/reports_local` نسخه HTML و JSON ذخیره می‌کند.

**تفاوت دو جزء مهم:** `ROBOT.bat` در ریشه مربوط به موتور پژوهشی Python و DEMO تحت مجوزهای جداگانه است. برای شروع کار با **Expert Advisor متاتریدر** از `START_HERE.bat` استفاده کنید. ساخت و اجرای آزمایش MT5 نیاز به نصب محیط Python ندارد.

## آزمایش Strategy Tester با ۳۰۰۰ دالر

در MT5 کلید `Ctrl + R`:

| گزینه | مقدار |
|---|---|
| Expert | `QTS_Gold_Robot` |
| Symbol | `XAUUSD@` |
| Timeframe | `M15` (بعداً M5 جداگانه) |
| Model | Every tick based on real ticks |
| Deposit | **۳۰۰۰ دالر** مطابق حداقل قابل‌انتخاب در ترمینال شما |
| `EnableDemoOrders` | `true` **فقط در Strategy Tester** |
| `TesterIgnoreDailyAndPeakStops` | `true` برای مشاهده فرصت‌های پس از باخت |
| `RiskPerTradePct` | `0.5` مبنای آزمایش، نه نسخه قطعی |
| `EntryStyle` | 0، 1، 2، 3 در **چهار تست مستقل** |
| `EnableEntryDiagnostics` | `true` |

`EntryStyle=2` روش شکست، تثبیت و Retest تأییدشده است. `EntryStyle=3` Sweep و برگشت تأییدشده است، اما در نمونه‌های تاریخی قبلی روش مشابه نتیجه ضعیف داشته؛ انتخاب آن به معنی تأیید سودآوری نیست.

**محدودیت‌های افت روزانه و سقف تعداد سفارش‌ها فقط در Strategy Tester** با `TesterIgnoreDailyAndPeakStops=true` کنار گذاشته می‌شوند. حد ضرر واقعی هر معامله، محدودیت حجم، اسپرید، کمیسیون مدل‌شده، مارجین، محدودیت زمانی و توقف خطای اجرایی فعال می‌مانند. حساب واقعی قفل است.

## گزارش‌ها را اشتباه تفسیر نکنید

دو گزارش متفاوت داریم:

**گزارش آمادگی** که با گزینه 2 تولید می‌شود: وضعیت فایل‌ها، کامپایل، Broker Preflight، حداقل لات، اسپرید و بودجه ریسک. اگر گزارش بروکر قدیمی باشد یا فایل EX5 با سورس فعلی مطابقت نداشته باشد، وضعیت `ACTION_REQUIRED` نشان داده می‌شود. «Ready for Tester» صرفاً مجوز **آزمایش** است.

**Presetهای مقایسه چهار استراتیژی:** از `START_HERE.bat` گزینه **5** را انتخاب کنید. چهار فایل `.set` در `gold_robot/reports_local/tester_presets` ساخته می‌شوند. در MT5 Strategy Tester → Inputs → Load یکی را انتخاب کنید و در Settings سرمایه **۳۰۰۰ دالر** و Every tick based on real ticks بگذارید. فایل‌ها تنظیمات دیگر را برابر و `EnableDemoForwardOrders=false` نگه می‌دارند؛ اجرای سفارش با حساب متصل از طریق این فایل‌ها مجاز نیست.

**گزارش مقایسه:** پس از چهار Backtest، از هر اجرا یک فایل HTML ذخیره کنید و با نام‌های `QTS_0.htm`، `QTS_1.htm`، `QTS_2.htm`، `QTS_3.htm` داخل `gold_robot/reports_local/native` قرار دهید. سپس گزینه **6** منوی اصلی را بزنید؛ فایل HTML/JSON با خلاصه تعداد معاملات، سود/زیان، Profit Factor و حداکثر افت Equity ساخته می‌شود. این ارقام native هستند و بدون تأیید همه هزینه‌ها به معنی سود خالص واقعی نیستند.

**گزارش معاملات** که باید از Strategy Tester ذخیره شود: `Backtest Report`، `Deals`، `Orders` و `Journal`. برای تحلیل Stopهای فعال‌شده و برگشت قیمت، تیک‌های Bid/Ask با زمان درست نیز لازم‌اند. هیچ گزارشی با ۰ معامله به معنی سودآوری نیست.

گزارش‌های تولیدشده، سوابق بروکر و فایل‌های اجرایی به GitHub ارسال نمی‌شوند. اسکرین‌شات و گزارش‌هایی که شریک می‌کنید باید فاقد رمز عبور و اطلاعات شخصی حساب باشند.

## رفع مشکلات رایج

- **MetaEditor پیدا نشد:** در MT5 کلید `F4` بزنید و محل فایل `metaeditor64.exe` متعلق به همین ترمینال را انتخاب کنید.
- **چند MT5 وجود دارد:** همان `Data Folder` را انتخاب کنید که در MT5 از `File → Open Data Folder` باز می‌شود.
- **خطای SHA-256:** سورس از شاخه main را در فولدر تازه Clone کنید، نه نسخه‌های قدیمی مخلوط.
- **کامپایل صفر خطا ندارد:** نصب‌کننده نسخه قبلی را برمی‌گرداند؛ متن کامل Compile Log را بررسی کنید.
- **گزارش `BLOCKED_MIN_LOT...`:** این محدودیت حجم/ریسک است؛ Stop را فقط برای بازکردن معامله کوچک نکنید.
- **سیگنال وجود ندارد یا سفارش ثبت نمی‌شود:** اول `EnableDemoOrders`، وجود تیک واقعی، سقف اسپرید، بازبودن بازار و `Experts/Journal` را در **Strategy Tester** بررسی کنید. هیچ سیگنال بازده مثبت را تضمین نمی‌کند.
- **گزارش وضعیت قدیمی:** Broker Preflight را دوباره اجرا کنید، سپس گزینه 2 را بزنید.

## آخرین معیار تحویل

**نصب/گزارش ویندوز:** کد و آزمون‌های GitHub حاضرند؛ کامپایل نسخه جدید روی خود ترمینال شما هنوز باید تأیید شود. **ربات قابل استفاده با پول واقعی نیست**؛ سودآوری پس از هزینه‌ها هنوز ثابت نشده است. گزارش‌های قبلی بعضی استراتیژی‌ها نتیجه منفی داشته‌اند.
